# Hausofit - store facts for the DM agent

Edit this file when prices, shipping or policies change. The agent answers ONLY from what is written here.

## Brand
- Hausofit: women's activewear + lifestyle, vintage look. Instagram @hausofit.official.
- Website: https://hausofit.co.il (Hebrew). Orders are placed on the site.
- Lines: FLOW, NOHUT, MIVNI, FORMA, OR SHINI. Also the V70S jumpsuit.

## Prices and stock
- Never from this file. The agent reads them live from the site with its tools,
  so a price change on the site is picked up within 10 minutes.

## Shipping
- Delivery: up to 5 business days.
- Shipping: 50 ILS. Free shipping on orders over 350 ILS.

## Payment
- On the site: Apple Pay, Google Pay, credit card, Bit, cash on delivery.

## Returns
- Returns within 7 days.

## Sizes
- Most items come in XS/S to XL. FLOW and NOHUT go up to XL only (no 2XL/3XL).
- Every product page has a size table and the size finder "רוצה עזרה במידה שלך?". The agent
  uses the same finder through the recommend_size tool (height+weight, bra size or measurements).

## Local words customers use (Arabic speakers in Israel mix in Hebrew)
Understand these and answer using the SAME word the customer used.
- تايتس / تايت / טייץ = leggings
- طايتس قصير / شورتس / شورت = shorts or bike shorts
- طوب / توب / טופ = sports bra (the bra/bra top of our sets). NOT a shirt, NOT a jacket.
  If she says توب/طوب, answer about our sports bras only.
- حزيه / حازيه / ستيان / صدرية / חזייה = bra, sports bra
- سيت / سط / طقم / סט = set
- ميداه / ميدا / מידה = size
- مشلوح / משלוח = shipping, delivery
- هزمناه / هزمنا / הזמנה = order
- هنحا / هناحا / הנחה = discount
- مڤتساع / مبتساع / מבצע = sale, special offer
- كود / קוד = discount code
- بيت / ביט = Bit payment app
- كرتيس / كرطيس اشراي / כרטיס אשראי = credit card
- تشلوم / תשלום = payment
- هحزراه / החזרה = return; هحلفاه / החלפה = exchange
- أتار / אתר = the website
- مليه / ملاي / מלאי = stock
- جاكيط / جاكيت / ז'קט = jacket
- چاتكس / חצאית = skirt

## Things the agent does NOT know (pass to a human)
- Exact stock of a specific size/colour.
- Order status, tracking, changes to an existing order, refunds.
- Wholesale, collaborations, influencers, complaints.
